# Smart Spending with AI

Smart Spending with AI is an intelligent personal finance management platform designed to help individuals track income, manage expenses, plan budgets, and optimize savings. Built with ASP.NET, C#, and MySQL, the platform leverages Artificial Neural Networks (ANN) and Long Short-Term Memory (LSTM) models to analyze spending behavior, predict overspending risks, and offer data-driven financial advice.

---

## Key Features

* **AI-Driven Predictive Analytics:** Analyzes historical spending patterns using ANN and LSTM models to predict financial risks and recommend budget adjustments.
* **Interactive Financial Dashboards:** Visual representations of income, expenses, and savings via charts and graphs.
* **Smart Expense Tracking & Budgeting:** Automated tracking of financial transactions with real-time budget threshold alerts.
* **Conversational AI Chatbot:** Interactive assistant that answers user queries and provides instant financial advice.
* **Real-Time Stock Insights:** Market data integration to boost investment awareness.
* **Administrative Control:** Role-based panel for user management, dataset configuration, and system oversight.

---

## System Architecture

The project is structured into a modular, multi-layered architecture:

1. **Presentation Layer:** ASP.NET Web Forms, HTML5, CSS3, and JavaScript for an intuitive frontend interface.
2. **Business Logic Layer:** C# code handling data validation, budgeting logic, and application workflows.
3. **Data Processing Layer:** Handles data cleaning, missing value handling, and feature extraction (e.g., savings ratio, budget utilization).
4. **AI/ML Layer:** Implements Neural Network (ANN) models trained on preprocessed data to generate predictions.
5. **Database Layer:** Microsoft SQL Server (MSSQL) storing user profiles, transaction logs, and analytical data.
